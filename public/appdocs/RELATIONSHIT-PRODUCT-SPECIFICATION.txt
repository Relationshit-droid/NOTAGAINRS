1. APP OVERVIEW & BRANDING
1.1 App Name
Relationshit!

1.2 Tagline
"Who said therapy?"

1.3 Core Concept
A mobile-first, gamified couples therapy app hosted by a brutally honest AI (Dr. Marcie Liss) that turns relationship repair into a competitive, witty, and deeply healing game. This is a game first, therapy second. The most important part is that it feels like a game because IT IS A GAME.

1.4 App Purpose
The core purpose is to deliver brutally honest therapy disguised as fun, using game mechanics to foster growth and repair relationships by transforming the difficult healing process into an engaging, fun competition — turning tough conversations into a game you can win together.

1.5 Key Principles
Game-First, Therapy-Second: All interactions are gamified with points, levels, achievements

Couple-Centric Design: The couple is the primary "player" unit

Dr. Marcie as Game Host: She's your arcade host, not your therapist

Mobile-First Arcade Feel: Optimized for portrait touch with thumb-accessible controls

3-Tap Navigation Rule: From any screen to core gameplay in 3 taps or less

Immediate Feedback: Every action gets visual, audio, and haptic response within 100ms

3. COMPLETE VISUAL DESIGN SYSTEM
3.1 Color Philosophy
Color is emotional choreography, not functional coding. Colors flow, repeat, and create mood rhythm across the experience. No rigid color coding (❌ green=success, red=danger). Think: "A rhythm of color that feels alive."

text
#db147c → #f05d68 (horizontal gradient)
Used for: EVERY primary and secondary button, CTAs, confirmations

Pressed State: 10% darker + 95% scale animation

7. 60 GAME IMPLEMENTATION DETAILS
7.1 The 30 Gottman Games
Game 1: 🎯 "Bid Radar"
Frontend: React Native component with 60-second timer, bid submission input, real-time partner sync (Firebase Realtime Database), animated matches display

Backend: Firebase Cloud Function for Google Gemini AI analysis of bid matches, real-time Firebase sync, Marcie commentary generation

Database: Firestore bidsRadar/{sessionId} with bids array, matches object, timestamps

AI Integration: Google Gemini for semantic similarity analysis between bids

Game 2: 💬 "Gentle Start-Up Gauntlet"
Frontend: Timer-based phrase rewrite interface, scoring display, round progression

Backend: Firebase Cloud Function analyzing I-statements, structure validation, tone scoring

Database: Firestore gentleStartup/{sessionId}/rounds with original phrases, rewrites, scores

AI Integration: Google Gemini NLP analysis for "I feel... about... I need..." structure detection

Game 3: 🧠 "Love Map Speedrun"
Frontend: Quiz interface with timer, answer input, real-time partner comparison

Backend: Firebase Cloud Function generating personalized questions from couple data (Firestore)

Database: Firestore loveMap/{sessionId} with questions array, answers objects, accuracy scores

AI Integration: Google Gemini generating personalized questions based on couple history

Game 4: 🛡️ "Antidote Arena"
Frontend: Audio clip player with buzz-in buttons, multiple choice antidote selection

Backend: Firebase Cloud Function playing Four Horsemen clips (Firebase Storage), validating antidote choices

Database: Firestore antidoteArena/{sessionId} with clips played, responses, streak counter

AI Integration: Google Cloud Text-to-Speech for audio clip generation, Google Gemini for scenario creation

Game 5: 🪞 "Mirror Mode"
Frontend: Video recording interface with prompts, playback comparison, word matching

Backend: Firebase Cloud Function processing video responses (Firebase Storage), tone analysis, word matching

Database: Firestore mirrorMode/{sessionId} with video URLs, transcripts, emotional scores

AI Integration: Google Gemini for face/emotion detection, voice sentiment analysis

Game 6: 🕵️ "Dream Decoder"
Frontend: Surface conflict input, clue system, guess interface, reveal animation

Backend: Firebase Cloud Function generating underlying dream patterns from conflicts

Database: Firestore dreamDecoder/{sessionId} with surface conflicts, underlying dreams, matches

AI Integration: Google Gemini analyzing conflicts to reveal deeper emotional needs

8. SOS FIGHT SOLVER SYSTEM
8.1 Overview
The SOS Fight Solver is an emergency conflict resolution system that provides real-time, AI-mediated intervention for couples in active conflict. It guides partners through structured reflection, provides neutral analysis, and generates actionable repair attempts.

8.2 Trigger Mechanism
Floating SOS Button: Fixed position bottom-right on EVERY screen

Visual: Pulsing red gradient animation (#E11637 to #FA1F63)

Icon: Infinite symbol with heart (❤️∞)

Z-index: 1001 (always accessible)

Action: User presses → screen dims → Marcie appears

8.3 Emergency Flow
Step 1: Emergency Activation
Screen dims 70%

Emergency modal appears

Dr. Marcie: "Put down the weapons. To the booths. Now."

Button: "ENTER BOOTHS" (gradient red)

Step 2: Soundproof Booths
Split-screen view with frosted glass effect

Left: "My Side" (current user)

Right: "Their Side" (partner - disabled until they join)

5-minute timer for unstructured text

Users vent freely in private space

Step 3: Structured Reflection (Mad Libs)
After venting, users must complete:

text
I feel [Emotion Dropdown: Angry, Hurt, Scared, Lonely, Frustrated, Disappointed, Confused, Betrayed, Ignored, Stressed]
When my partner [Specific Action: "texts during dinner"]
Because I tell myself the story that [Interpretation: "I'm not important"]
What I actually need is [Need: "Undivided attention for 30 minutes"]
Step 4: The Hold (Cool-Down Room)
First finisher enters "Waiting Room"

Mini-games available:

Breathing exercise (visual guide)

Distraction puzzles (simple games)

Happy Memory Gallery (photos)

Dr. Marcie commentary: "Breathe. They're almost done."

Timeout after 2 hours → automatic escalation to professional resources

Step 5: AI Verdict & Roast (Google Gemini)
Analysis of both partners' inputs

Pulls from: History, Origin Story, Personality Types, Previous Fights

Output Structure:

What You Did Right: Validation (e.g., "Alex, good 'I feel' statement. +10 VP")

The Call-Out: Roast (e.g., "Jordan, stonewalling detected. Penalty: -15 CP")

The Reality Check: Insight (e.g., "You're fighting about dishes, but the issue is respect.")

Who Owes Apology: Direction (e.g., "Jordan → Alex")

Repair Steps: 3 actionable suggestions

Step 6: Repair Attempt Selection
3 repair options generated by Google Gemini

Each partner chooses one

Timer: 10 minutes to complete

Examples:

"Share 3 specific appreciations"

"Physical touch (hand hold) for 2 minutes"

"Plan a 'do-over' conversation"

Step 7: Post-Repair Questionnaire
5 questions (Yes/No/Maybe)

"Did the repair attempt help?"

"Do you feel heard?"

"Was the repair specific enough?"

"Did it address the core issue?"

"Would you try this again?"

Points awarded based on mutual agreement

Real-time Sync: Firebase Realtime Database

AI Analysis: Google Gemini via Firebase Cloud Functions

Context Injection: History Log, Origin Story, Personality Types

Push Notifications: FCM when partner joins SOS session
