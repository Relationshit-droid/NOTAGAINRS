## Format Requirements
- **Format**: MP3 (primary), OGG (fallback)
- **Sample Rate**: 44.1kHz
- **Bitrate**: 128kbps (effects), 192kbps (voice/music)
- **Duration**: 0.5-3s (effects), 10-30s (ambient loops)
- **Normalization**: -14 LUFS (streaming standard)
- **Loop**: Ambient tracks must loop seamlessly
