# Video Assets Required

## Splash Video
- **marcie-intro.webm** - Dr. Marcie introduction video (10-15 seconds)
  - Used on SplashScreen
  - Should be 1080x1920 (portrait) or 1920x1080 (landscape)
  - WebM format with VP9 codec for best compression
  - Loop-friendly, no audio required

## Dr. Marcie Animations (16 WebM files)
Each animation should be 3-5 seconds, transparent background (WebM with alpha), 512x512px:

1. **marcie-idle.webm** - Breathing, subtle movement
2. **marcie-listening.webm** - Leaning in, attentive
3. **marcie-thinking.webm** - Chin stroke, contemplative
4. **marcie-sassy.webm** - Eyebrow raise, smirk
5. **marcie-shocked.webm** - Wide eyes, dramatic gasp
6. **marcie-correct.webm** - Thumbs up, nodding
7. **marcie-wrong.webm** - Head shake, "tsk tsk" finger wag
8. **marcie-impatient.webm** - Foot tap, watch check
9. **marcie-warning.webm** - Finger point, serious face
10. **marcie-playful.webm** - Wink, playful gesture
11. **marcie-concerned.webm** - Brow furrow, gentle lean
12. **marcie-celebrating.webm** - Confetti, happy dance
13. **marcie-suspicious.webm** - Narrow eyes, lean back
14. **marcie-proud.webm** - Chest puff, smile
15. **marcie-whisper.webm** - Finger to lips, lean in
16. **marcie-goodbye.webm** - Wave, fade out

## Format Requirements
- **Codec**: VP9 (WebM) with alpha channel support
- **Resolution**: 512x512px (animations), 1080x1920 (splash)
- **Frame Rate**: 30fps
- **Duration**: 3-5s (animations), 10-15s (splash)
- **Loop**: Animations should loop seamlessly
- **Transparent Background**: Required for animations (not splash)

## Production Notes
- Create in After Effects + Bodymovin/Lottie export to WebM
- Or use Rive/Spine for skeletal animations
- Keep file sizes under 500KB each for animations
- Splash video under 5MB
